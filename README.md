Через жорсткі оновлення безпеки, впроваджені Spotify, для роботи додатку обов'язково необхідно мати підписку Spotify Premium.

Щоб запустити додаток, необхідно отримати два токени: один з них потрібний для роботи з Spotify API, для отримання метаданих про треки, альбоми й виконавців, керування плейлістами, а інший дає повний доступ до функцій відтворення музики через Spotify Web Playback SDK.
Зауважимо, що токени діють рівно 1 годину (3600 секунд). Після цього вони анулюються.

Щоб отримати токен для роботи з Spotify API, вам потрібно пройти процес авторизації через Spotify for Developers (https://developer.spotify.com/).

Далі виконайте такі кроки:
1) Відкрийте панель розробника у браузері (натисніть клавішу F12, або правою кнопкою миші -> Переглянути код / inspect).
2) Перейдіть на вкладку Network (Мережа).
3) Оновіть сторінку (натисніть клавішу F5), щоб відправити запити.
4) У списку мережевих запитів знайдіть рядок me.
5) Натисніть на цей запит і праворуч оберіть вкладку Headers (Заголовки).
6) Прокрутіть вниз до розділу Request Headers (Заголовки запиту).
7) Знайдіть рядок authorization: Bearer ... 
8) Скопіюйте довгий набір символів, який йде одразу після слова Bearer.
9) Відкрийте файл key.js у папці js додатку та вставте скопійований токен між лапок до поля const token = "".

Цей токен крім прав отримання метаданих про треки, альбоми й виконавців, ще дає права для отримання даних користувача.

Далі необхідно отримати токен для відтворення музики.

Виконайте такі кроки:
1) Перейдіть на сторінку Web Playback SDK (https://developer.spotify.com/documentation/web-playback-sdk).
2) У лівій колонці виберіть пункт Getting Started.
3) Прокрутіть сторінку вниз до кнопки "Reveal your access token" і натисніть на неї.
4) Скопіюйте токен, що з'явився.
5) Відкрийте файл key.js у папці js додатку та вставте скопійований токен між лапок до поля const tokenSDK = "".
6) Збережіть файл key.js.

Тепер можна запустити додаток, відкривши файл index.html за допомогою Live Server для VS Code чи аналогічного локального сервера.
